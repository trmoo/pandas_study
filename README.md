# 🐼 판다스 실습실

**설치 없이, 인터넷 없이, 브라우저에서 판다스(pandas) 명령을 직접 실행하며 배우는 실습실**입니다.
시리즈·데이터프레임부터 결측치·groupby·merge·시계열까지, 그리고 빅데이터분석기사 작업형1 꼴 미션과 치트시트까지 담았습니다.

👉 바로 열기: **https://trmoo.github.io/pandas_study/**

- 빈칸을 채워 ▶ 실행하면 결과를 **코랩과 같은 판다스 2.2 의 출력 그대로** 보여 주고, 정답인지 바로 알려 줍니다.
- 정답과 다르게 써도 **결과가 같으면 정답**으로 인정합니다. 💡 힌트는 세 단계(설명 → 첫 글자 → 정답 넣기).
- 학생 이름·학번을 받지 않습니다. 기록은 그 브라우저(localStorage)에만 남고 [🧹 내 기록 지우기] 로 지웁니다.

## 수업에서 쓰는 법

1. 학생에게 주소를 알려 줍니다. 인터넷이 없는 교실이라면 `dist/index.html` 한 파일을 나눠 주세요 — 더블클릭으로 열립니다.
2. 교사 화면에서는 레슨 위의 [👩‍🏫 정답 채우기] → [▶ 위에서부터 모두 실행] 으로 한 번에 시연할 수 있습니다.
   주소 끝에 `?demo` 를 붙이면(예: `…/pandas_study/?demo#summary/groupby`) 열자마자 정답으로 실행해 둡니다.
3. 주소 끝의 `#단원/레슨` 으로 화면을 바로 열 수 있습니다 — 예) `#select/locs` · `#clean/strings` · `#mission/missions`.

## 이 실습실의 파이썬

파이썬·판다스를 브라우저 안에서 흉내 내는 **자체 엔진**(`src/engine/`)으로 돌아갑니다. 설치·인터넷·기다림이 없는 대신,
아직 흉내 내지 못하는 명령은 🚧 로 정직하게 알려 줍니다(예: `sample( )`, `query( )`, 머리글이 두 줄인 표).

- 레슨·미션의 **모든 셀**과 학생이 쳐 볼 만한 시험 코드 수백 개를 **진짜 pandas 2.2 의 결과와 글자 하나까지** 대조합니다(`npm test`).
- 같은 값끼리의 정렬 차례는 진짜 판다스에서도 컴퓨터(CPU)마다 다를 수 있습니다. 이 실습실은 늘 원래 차례를 지킵니다.

## 데이터

`src/data/` 의 CSV 다섯 개는 모두 **이 실습실을 위해 지어낸 자료**입니다(`tools/make_data.py`).
별빛 분식 메뉴판·주문 기록, 바람섬 날씨, 한빛시 공유자전거 기록 — 가게·섬·도시 이름도 지어낸 것입니다.

## 만들기 (개발자용)

```bash
npm install
npm start               # 개발 서버
npm test                # 엔진·레슨 점검 (진짜 판다스 기준과 대조)
npm run check:syntax    # 소스 전수 문법·저작권 머리 주석 점검
npm run build           # dist/index.html (한 파일) + dist/cheatsheet.html
npm run pdf             # docs/판다스_치트시트.pdf (이 PC 의 크롬·엣지로)
```

기준 출력 다시 만들기(판다스 2.2 가 깔린 파이썬이 필요합니다):

```bash
npm run scenarios
python tools/golden.py
python tools/verify_cheatsheet.py
```
